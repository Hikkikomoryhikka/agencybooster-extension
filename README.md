# AgencyBooster — расширение для Chrome

Расширение для сайта **goldenbride**. Есть **две версии** — выбери одну. Они **одинаковые во всём** (панель клиентов, отслеживание писем, черновики всем, «🚫 Не трогать», авто-инвайты в чат, чистка текста и переводчик в Live chat, защита от спам-фильтра), **разница только в том, как работает ИИ**, который пишет письма.

| | 🗂 Обычная | ⚡ С API |
|---|---|---|
| Как работает ИИ | через открытые вкладки ChatGPT, Gemini, Grok, DeepSeek и др. (нужно войти в эти сайты) | напрямую через **бесплатный API-ключ** Gemini / Groq / OpenRouter — вкладки не нужны |
| Скорость письма | дольше: ИИ печатает в своей вкладке | несколько секунд |
| Переводчик в чате (только по кнопке 🌐 EN) | через Google | ИИ с ключом: разговорный английский со сленгом (без ключа — Google) |
| Нужно один раз | войти в аккаунты ИИ-сайтов в Chrome | получить бесплатный ключ (см. ниже) и вставить в расширение |

## 🧩 Установка (один раз)

1. Распакуй скачанный zip в папку, которую не будешь удалять (например, `Документы\AgencyBooster`).
2. Открой в Chrome адрес `chrome://extensions`.
3. Справа вверху включи **«Режим разработчика»**.
4. Нажми **«Загрузить распакованное расширение»** и выбери эту папку.
5. Готово — открой goldenbride и обнови страницу.

> ❗ **Не ставь обе версии сразу** — они будут мешать друг другу (двойные инвайты, двойные черновики). Чтобы перейти на другую версию: в `chrome://extensions` нажми «Удалить» у старой, потом установи новую.

## 🔄 Обновление

1. Скачай новую версию по той же ссылке выше.
2. Распакуй её **в ту же папку**, заменив файлы. (Для версии с API это важно: ключи привязаны к расширению — если поставить его из другой папки, ключи придётся вставить заново.)
3. В `chrome://extensions` нажми ⟳ у AgencyBooster.
4. Обнови вкладки goldenbride (и Live chat).

Номер версии видно в `chrome://extensions`.

## 🔑 Как получить бесплатный API-ключ (для версии с API)

Нужен ключ **хотя бы одного** ИИ, лучше всех трёх: когда у одного кончается бесплатный лимит, письмо пишет следующий. Карта не нужна, всё бесплатно.

**Куда вставлять:** панель AgencyBooster → «Настройки ✍️ ИИ» → у нужного ИИ кнопка **«🔑 Ключ»** → вставь ключ → OK. Расширение сразу проверит ключ и напишет «✓ Ключ … работает». Кнопка «Где взять?» открывает нужную страницу.

### Gemini (Google) — пишет лучше всех, обычные темы
1. Открой **https://aistudio.google.com/apikey** и войди своим Google-аккаунтом (тем же, что для Gmail).
2. При первом входе прими условия (галочки и «Continue»).
3. Нажми **«Create API key»** (если спросит проект — выбери любой или «Create API key in new project»).
4. Скопируй ключ (начинается с `AIza…`) и вставь в расширение.

> Если пишет, что сервис недоступен в твоей стране — нужен VPN только на момент получения ключа, либо используй Groq и OpenRouter.

### Groq — самый быстрый, для чата и переводчика
1. Открой **https://console.groq.com/keys** и войди (кнопка Google или по почте).
2. Нажми **«Create API Key»**, впиши любое название (например `booster`) → «Submit».
3. Скопируй ключ (начинается с `gsk_…`) — **он показывается один раз**, сразу вставь в расширение.

### OpenRouter — для откровенных тем
1. Открой **https://openrouter.ai/settings/keys** и войди (Google или почта).
2. Нажми **«Create Key»**, впиши любое название, лимит (Credit limit) можно оставить пустым → «Create».
3. Скопируй ключ (начинается с `sk-or-…`) — **он показывается один раз**, сразу вставь в расширение.

> Бесплатные лимиты: Gemini и Groq — сотни писем в день, OpenRouter — около 50 запросов в день. Когда лимит кончился, ИИ «отдыхает» и письма пишет следующий; ничего делать не надо.
>
> 🔒 Ключ хранится только в твоём Chrome и отправляется только в свой ИИ. Никому его не пересылай. Ключи вводятся в каждом профиле Chrome отдельно.

## 💬 Правила авто-рассылки приглашений в чат (goldenbride)

Сайт в разделе **Rules** требует: до начала платного чата писать одному и тому же мужчине **не чаще раза в минуту**, разным мужчинам — **не чаще раза в 5 секунд**, только латиница, без эмодзи. Мужчина может пожаловаться на спам приглашениями (например, 5 подряд) — тогда штраф агентству.

Расширение (обе версии) рассылает так:

- **Темп:** одно сообщение раз в **7 секунд** (строже, чем 5 с у сайта).
- **Одному мужчине — не чаще раза в 30 минут.**
- **Тем, кто не отвечает:** после 2 приглашений без ответа — пауза **1 час**, дальше не чаще **одного в час** и **не больше 4 без ответа за сутки** (5 подряд сайт называет спамом). Как только мужчина ответил или начался платный чат — счётчик начинается заново.
- **Не пишет:** тем, кто в чёрном списке (твой BL, BL сайта, BL расширения); тому, с кем сейчас идёт разговор (30 минут после его сообщения); тому, кому ты сама написала руками (10 минут); тем, кто не в сети.
- **Текст:** перед первой отправкой проверяется — только латиница и без эмодзи. Проверь сама, что в тексте нет опечаток в `{name}` — за приглашение с видимым тегом сайт штрафует.
- **Пока ты печатаешь в чате**, рассылка ждёт, чтобы сообщения не ушли подряд.
- **Если сайт ответил** «слишком быстро» или «лимит» — рассылка сама делает паузу и этому мужчине не пишет, пока сайт не разрешит.

Твои ручные сообщения расширение не ограничивает — следи сама: до платного чата одному мужчине не чаще раза в минуту.

## 🚫 Спам-фильтр сайта

Сайт отбраковывает письма и сообщения с некоторыми словами (весь список неизвестен). Точно попадают: **mail, email, e-mail, mailbox, inbox, fuck, pussy, masturbate, spank** — в любой форме (fucked, pussies, masturbating, spanking…).

Расширение (обе версии) **само заменяет их разрешёнными словами**:

| Было | Станет |
|---|---|
| mail, email, e-mail, mailbox, inbox | letter (letters) |
| fuck you / fucked me | make love to you / made love to me |
| fucking (как усилитель) | freaking |
| pussy | kitty |
| masturbate, masturbating | touch myself, touching myself |
| spank, spanking | smack, smacking |

Где работает: письма, которые пишет ИИ, **письма, которые ты пишешь сама**, текст Mail Bot, строка-приглашение к письму, авто-рассылка инвайтов, кнопка «💬 Инвайт» и **твои собственные сообщения в Live chat**. ИИ к тому же прямо запрещено использовать эти слова.

В письмах и в Mail Bot текст исправляется, когда уходишь из поля или жмёшь отправить: заодно убираются длинные тире и точки с запятой. Переносы строк и `{name}` не меняются.

## ✉️ Правила писем сайта (для справки)

- До платного общения: письмо одному мужчине раз в 7 дней, от 500 символов, только английский.
- Если было платное общение за последние 7 дней — лимит писем в сутки не действует.
- Mail Bot: до 300 писем в сутки. Одинаковые тексты одному мужчине повторно отправлять нельзя.

Панель расширения показывает, кому можно писать прямо сейчас («Можно писать») и сколько писем осталось на сегодня.
