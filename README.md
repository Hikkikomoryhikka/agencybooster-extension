# AgencyBooster — расширение для Chrome

## 📥 Скачать

**[⬇ Скачать последнюю версию](https://github.com/Hikkikomoryhikka/agencybooster-extension/releases/latest)** → в разделе «Assets» нажми на файл `AgencyBooster-extension-….zip`.

## 🧩 Установка (один раз)

1. Распакуй скачанный zip в папку, которую не будешь удалять (например, `Документы\AgencyBooster`).
2. Открой в Chrome адрес `chrome://extensions`.
3. Справа вверху включи **«Режим разработчика»**.
4. Нажми **«Загрузить распакованное расширение»** и выбери эту папку.
5. Готово — открой мультик (ma.social-booster.agency) или goldenbride и обнови страницу.

## 🔄 Обновление

1. Скачай новую версию по той же ссылке выше.
2. Распакуй её **в ту же папку**, заменив файлы.
3. В `chrome://extensions` нажми ⟳ у AgencyBooster (или кнопку «⟳ Обновить расширение» в окне авто-инвайтов мультика).
4. Обнови вкладки мультика / goldenbride.

Номер версии видно в `chrome://extensions` и внизу окна авто-инвайтов.
